# 読者マップ

プロンプトには必ず「🎯想定読者」を1つ選んで明記する。複数狙いは薄まるので原則1プロンプト1読者。

## A. Vue/フロントエンド初中級者

- 特徴: 入門記事は読んだが実戦で躓く層。Qiitaでの主力読者
- 刺さる型: 型1（挫折者翻訳）、型5（実践Tips）
- 到達チャネル: Qiita

## B. Composition API / モダンフロントに乗り切れなかった層

- 特徴: Vue2時代の開発者、Options API愛好者。声を上げにくい多数派
- 刺さる型: 型2（あえて系）
- 到達チャネル: Qiita、X

## C. Claude Code / AIエージェント実践者

- 特徴: 一次情報に飢えている。伸び盛りで英語圏にも需要
- 刺さる型: 型6（AI協働）、型4（ツール物語）
- 到達チャネル: Zenn、dev.to（英訳）、LT会

## D. 個人開発者・OSS作者

- 特徴: 技術選定・モチベ維持・認知獲得に悩む層
- 刺さる型: 型3（失敗談）、型4（ツール物語）
- 到達チャネル: Zenn、note、LT会

## E. 登壇したい・発信したいエンジニア

- 特徴: マサカリが怖い、ネタがないと思い込んでいる
- 刺さる型: 型1×メタ（発信ノウハウ）、SOFT SKILLS系
- 到達チャネル: note、SpeakerDeck、社内LT

## F. Misskey / Fediverse 界隈

- 特徴: mfm-renderer などの実績で接点あり。ノリが独特で宣伝臭に敏感
- 刺さる型: 型3、型4（等身大の開発記）
- 到達チャネル: Misskey本体での交流

## チャネル使い分けの目安

- Qiita: 検索流入・ストック型Tips
- Zenn: 現在進行系の技術（AI系）、scrapでの過程公開
- note: 物語・キャリア・動機系
- SpeakerDeck+LT: 失敗談エンタメ、コミュニティ内の認知
- dev.to: 日本語で当たった記事の英訳二次利用
